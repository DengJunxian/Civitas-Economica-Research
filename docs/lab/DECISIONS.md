## 模型问题的决定（基线审计第 4 节）

| 编号 | 发现 | 决定 | 理由 |
| --- | --- | --- | --- |
| F1 | 无事件时价格下行约 9% | **保留模型，更正说明。** EXP-01 与 LESSON-MKT-002 改为描述实际机制 | 初始情绪平均为正、交易意图接近 0；情绪更新包含价格趋势项，早期下跌使意图持续转负，形成模型内的自我强化。原说明“初始条件造成”不准确。改模型需要研究验证，不属于教学层 |
| F2 | 默认 β=0.3 下恐慌几乎不扩散，EXP-06 无法比较拓扑 | **EXP-06 v0.2.0 公开设定 β=1.0**，写入假设与限制；EXP-05 保持默认 | 场景问题是“拓扑是否影响传播”，机制未被激活时比较没有意义。参数选择公开、可撤回，默认值下的零差异仍记录在审计与课堂包中。旗舰课把“传播是否发生取决于传播强度”作为讨论点 |
| F3 | 决策公式不读取印花税率 | **保持模型；EXP-08/09 讲授费用通道与零差异。** 成本敏感的决策规则放到规划中的 EXP-03（P2，交易成本与成交策略）并经专家验证 | 投资者对交易成本的行为反应是新的行为机制，凭空设定会把未经验证的假设当作教学结论 |
| F4 | 停牌撤单通常为 0 | 保留；EXP-07 证据描述已更正 | 订单默认存活 1 步，属于既有市场规则 |
| F5 | `market_regime` 在标准路径中只改变画像，无传播时输出逐字节相同，有传播时只影响 SIRS 覆盖、几乎不影响价格 | 能力门禁对非默认 regime 给出 `REGIME_LIMITED_EFFECT` 提示 | 防止教师把它当作牛市/熊市等市场状态变量 |

## 运行与治理默认值

| 事项 | 默认 | 可调 |
| --- | --- | --- |
| HTTP API 运行隔离 | 每个对照在独立子进程中运行（spawn），串行执行 | `CIVITAS_LAB_ISOLATION=thread` |
| 单个对照时间上限 | 900 秒；超时终止并在任务与归档中记为 `timeout`，进行中的运行记为 `interrupted` | `CIVITAS_LAB_RUN_TIMEOUT` |
| AI 预算 | 每日 30 次；课程与教师两级默认关闭 | `CIVITAS_LAB_AI_DAILY_CALLS`、`CIVITAS_LAB_AI_COURSE_DAILY_CALLS`、`CIVITAS_LAB_AI_TEACHER_DAILY_CALLS` |
| AI 请求人 | 自报的教师名，只用于预算统计，不是身份认证 | — |
| 课堂试点汇总 | 少于 5 人的单元格不显示；疑似学号、身份证号、邮箱的编号拒绝汇总 | `lab/pilot.py` 中的 `MIN_CELL` |

## 只能由所有者或课程负责人决定的事项

- **LICENSE（规划 R9）**：仓库没有许可证。选择许可证是对代码与教学内容权利的法律决定，工程上没有代为选择。发布衍生产品前需要确定。
