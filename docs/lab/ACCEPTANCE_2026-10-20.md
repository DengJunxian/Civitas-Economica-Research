# MVP 技术验收记录（2026-10-20，规划 9.1 / 9.3）

```sh
.venv/bin/python scripts/lab_acceptance.py
```

脚本在整个过程中阻止网络连接并移除 LLM API key 环境变量，写出 `outputs/lab-acceptance/<id>/acceptance.json`、每个场景的证据报告和全部运行归档，任一检查不通过即退出码 1。本记录是工程验收证据，不是市场真实性、教学有效性或真实模型质量的证据；课堂试点与教师审查（G3/G4）仍需另行完成。

环境：macOS 27.0 arm64，Python 3.12.13；提交 `866b300` 加上未提交的本轮改动（验收脚本、PDF 与试点表单导出），manifest 记 `git_dirty=true`。用时 69 秒。

## 结果：通过

| 检查（规划 9.1） | 方法 | 结果 |
