## 3. 核心改动：账本挂单索引（性能，不改变结果）

剖析显示单次运行 85% 的时间在 `ClearingHouse.active_orders`：每次资金/持仓检查都遍历全部历史订单，`check_invariants` 又对每个账户调用一次，整体随运行长度平方增长。改动在 `core/exchange/clearing.py` 中维护一个与 `orders` 插入顺序相同、剔除终态订单的 `_open` 索引；终态订单不会再变为有效，所以返回列表及其顺序与原实现一致。被预处理拒绝但状态仍为 PENDING 的订单同样进入索引，以保持原语义。

等价性证据：用**改动前代码**生成的 11 个归档（EXP-05 的 10 次配对运行 + `panic.yaml`），在改动后执行 `reproduce_run`，11 个均为 `matched`（11 个状态/结果文件逐字节相同）。另有单元测试在提交、成交、拒绝、撤单各步后对比索引与全量扫描。

效果：单次运行约 4.4 秒 → 约 0.45 秒；全部 7 个场景共 76 次运行加校验约 36 秒。

## 4. P1 场景实测与模型发现

以下为 `lab/content/scenarios/` 中各场景按规定种子（41–45；EXP-01 为 42）实际运行的结果，全部通过 `verify_comparison`。差异为"组 − 参考组"的逐种子配对差，括号内为正/负/零的种子数。

| 场景 | 主要结果 |
| --- | --- |
| EXP-01 | 179 笔成交；30 步中 22 步价差不可定义（一侧无挂单）；无事件下期末收益 −9.35% |
| EXP-02 情绪冲击 | 累计成交量 −47.6（0/5/0）；被拒订单 +3（5/0/0）；价差不可定义步数基本不变 |
| EXP-05 恐慌 | 卖出决策占比 +0.45 个百分点（5/0/0）；累计成交量 −9（0/5/0）；最大回撤仅 1 个种子有变化；恐慌峰值 ≈ 种子数 8 |
| EXP-06 拓扑 | 环形 vs 小世界的恐慌峰值差为 0（5 个种子全为 0）；无边网络 −0.6；成交与回撤差异方向不一致 |
| EXP-07 停牌 | 最大回撤 −0.46 个百分点（0/5/0）；零成交步 +2；卖出决策占比 −1.5 个百分点（0/5/0）；恐慌峰值不变 |
| EXP-08 降税 | 累计成交量、成交笔数、期末收益差均为 **0**（5 个种子全为 0）；只有累计费用 −77.6 |
| EXP-09 2×2 | 交互差异 Δ（累计成交量）在 5 个种子上均为 **0** |

由此得到四项影响教学设计的模型事实（均未修改模型，留待决策）：

- **F1 默认人口带卖出偏向。** 无事件时约 70–76% 的决策为卖出，30 步内价格下跌约 9%。所有场景都叠加在这条下行漂移上，EXP-01 的限制说明已写明这是初始条件而非市场规律。
- **F2 SIRS 传播在标准路径下很弱。** 感染概率 = β × 语义相似度 × 推荐热度 × 从众度；标准运行中相似度与热度约 0.17，每步感染概率约 0.005，恐慌自行消退，网络拓扑因此几乎不起作用（EXP-06 无可比差异）。探测：β=1.0 时环形/小世界峰值约 16/15、无边网络 8，拓扑差异出现，但价格与卖出占比差异仍很小。即传播强度与"感染 → 决策"耦合都偏弱。
- **F3 印花税不进入决策公式。** `agents/population.py` 的向量决策与 `FastAgentKernel` 都不读取税率；税率只改变卖方结算现金。10 步内的现金差不足以改变整数下单量，所以 EXP-08/09 的行为差异为 0。EXP-08/09 的限制说明已写明。
- **F4 停牌撤单通常为 0。** 默认订单存活 1 步，每步开始先按到期撤单再执行事件，停牌时已无挂单可撤。EXP-07 的证据描述已据此修改。
